# Ring Reduce-Scatter + AllGather 步骤表（3 Rank × 6 段）

> Ring AllReduce = **Reduce-Scatter**（分段规约到各 Rank）+ **AllGather**（沿环收齐，人人得完整结果）。本文按同一 3 Rank×6 段约定，分阶段写出每轮发送/接收与段状态。

## 概念区分

- **Rank（秩）**：参与通信的**进程**，本例共 **3 个**：R0、R1、R2。环上顺序为 R0 → R1 → R2 → R0。
- **段（Segment）**：数据的**划分单位**，本例共 **6 段**：段 0～段 5。每段在各 rank 上都有一个本地值，规约后得到该段的全局和。
- **块（Chunk）**：沿环**一次发送的单位**。本例把 6 段合并为 3 块：块 0 = 段 0+段 1，块 1 = 段 2+段 3，块 2 = 段 4+段 5。块 k 的规约结果最终归 **Rank k** 所有。

这样 **段数（6）≠ Rank 数（3）**，便于区分「数据划分」与「进程」。

---

# 阶段一：Reduce-Scatter（分段规约到各 Rank）

## 约定

- **环**：Rank 0 → Rank 1 → Rank 2 → Rank 0。
- **每轮**：每个 rank 向**右邻居**发 1 块（含 2 段），从**左邻居**收 1 块，收到后与本地**同段**做 **+=**；若收到的是某段的完整和 S，则用**替换**。
- **记号**：`aⱼ` = Rank0 的段 j 的本地值，`bⱼ` = Rank1 的段 j，`cⱼ` = Rank2 的段 j。段 j 的全局和 `Sⱼ = aⱼ+bⱼ+cⱼ`。归宿：**段 0,1 → R0；段 2,3 → R1；段 4,5 → R2**。

---

## 初始状态（Round 0 之前）

| 段 \ Rank | Rank 0 | Rank 1 | Rank 2 |
|-----------|--------|--------|--------|
| 段 0      | a₀     | b₀     | c₀     |
| 段 1      | a₁     | b₁     | c₁     |
| 段 2      | a₂     | b₂     | c₂     |
| 段 3      | a₃     | b₃     | c₃     |
| 段 4      | a₄     | b₄     | c₄     |
| 段 5      | a₅     | b₅     | c₅     |

---

## 发送规则（每轮谁发哪一块）

- **Round r**（r = 0,1,2）：Rank i **发送** 的块号 = `(i + r) mod 3`。  
  - Round 0: R0→块0(段0,1), R1→块1(段2,3), R2→块2(段4,5)  
  - Round 1: R0→块1, R1→块2, R2→块0  
  - Round 2: R0→块2, R1→块0, R2→块1  
- **Round 3**：每人把手中已收齐的块发给其**归宿 rank**，对方做**替换**。

- **接收**：从**左邻居**收 1 块（2 段），对同段做 **+=**；若收到的是完整和则**替换**。

---

## Round 0：发块 (i+0) mod 3

**发送/接收：**

| Rank | 发送               | 接收来自 | 操作 |
|------|--------------------|----------|------|
| 0    | 块0(段0,1) → R1 (a₀,a₁) | R2   | 段4 := a₄+c₄，段5 := a₅+c₅ |
| 1    | 块1(段2,3) → R2 (b₂,b₃) | R0   | 段0 := a₀+b₀，段1 := a₁+b₁ |
| 2    | 块2(段4,5) → R0 (c₄,c₅) | R1   | 段2 := b₂+c₂，段3 := b₃+c₃ |

**Round 0 结束后各 rank 的段状态：**

| 段 \ Rank | Rank 0   | Rank 1   | Rank 2   |
|-----------|----------|----------|----------|
| 段 0      | a₀       | a₀+b₀    | c₀       |
| 段 1      | a₁       | a₁+b₁    | c₁       |
| 段 2      | a₂       | b₂       | b₂+c₂    |
| 段 3      | a₃       | b₃       | b₃+c₃    |
| 段 4      | a₄+c₄    | b₄       | c₄       |
| 段 5      | a₅+c₅    | b₅       | c₅       |

## Round 1：发块 (i+1) mod 3

**发送/接收：**

| Rank | 发送                    | 接收来自 | 操作 |
|------|-------------------------|----------|------|
| 0    | 块1(段2,3) → R1 (a₂,a₃) | R2       | 段4 := (a₄+c₄)+b₄，段5 := (a₅+c₅)+b₅ |
| 1    | 块2(段4,5) → R2 (b₄,b₅) | R0       | 段0 := (a₀+b₀)+c₀=S₀，段1 := (a₁+b₁)+c₁=S₁ |
| 2    | 块0(段0,1) → R0 (c₀,c₁) | R1       | 段2 := (b₂+c₂)+a₂=S₂，段3 := (b₃+c₃)+a₃=S₃ |

**Round 1 结束后各 rank 的段状态：**

| 段 \ Rank | Rank 0   | Rank 1   | Rank 2   |
|-----------|----------|----------|----------|
| 段 0      | a₀+c₀   | a₀+b₀    | c₀       |
| 段 1      | a₁+c₁   | a₁+b₁    | c₁       |
| 段 2      | a₂       | a₂+b₂    | **S₂**   |
| 段 3      | a₃       | a₃+b₃    | **S₃**   |
| 段 4      | a₄+c₄   | **S₄**   | b₄+c₄    |
| 段 5      | a₅+c₅   | **S₅**   | b₅+c₅    |

此时：段 2,3 的完整和已在 **R2**；段 4,5 的完整和已在 **R1**。段 0,1 仍分散在 R0/R1/R2，需下一轮收齐。

---

## Round 2：发块 (i+2) mod 3

**发送/接收：**

| Rank | 发送                      | 接收来自 | 操作 |
|------|---------------------------|----------|------|
| 0    | 块2(段4,5) → R1 (a₄+c₄, a₅+c₅) | R2   | 收到块1 (S₂,S₃) → 段2:=S₂，段3:=S₃（替换） |
| 1    | 块0(段0,1) → R2 (a₀+b₀, a₁+b₁) | R0   | 收到块2 → 段4:=(a₄+c₄)+b₄=S₄，段5:=S₅ |
| 2    | 块1(段2,3) → R0 (S₂,S₃)  | R1       | 收到块0 → 段0:=(a₀+b₀)+c₀=S₀，段1:=(a₁+b₁)+c₁=S₁ |

**Round 2 结束后各 rank 的段状态：**

| 段 \ Rank | Rank 0   | Rank 1   | Rank 2   |
|-----------|----------|----------|----------|
| 段 0      | a₀+c₀   | a₀+b₀    | **S₀**   |
| 段 1      | a₁+c₁   | a₁+b₁    | **S₁**   |
| 段 2      | **S₂**   | a₂+b₂    | S₂       |
| 段 3      | **S₃**   | a₃+b₃    | S₃       |
| 段 4      | a₄+c₄   | **S₄**   | b₄+c₄    |
| 段 5      | a₅+c₅   | **S₅**   | b₅+c₅    |

---

## Round 3：把完整块送到归宿 Rank（替换）

每人把手中已收齐的**整块**发给该块的归宿 rank，对方用**替换**写入对应段。

**发送/接收：**

| Rank | 发送               | 接收来自 | 操作（替换） |
|------|--------------------|----------|--------------|
| 0    | 块1(S₂,S₃) → R1    | R2 块0   | 段0:=S₀，段1:=S₁ |
| 1    | 块2(S₄,S₅) → R2    | R0 块1   | 段2:=S₂，段3:=S₃ |
| 2    | 块0(S₀,S₁) → R0    | R1 块2   | 段4:=S₄，段5:=S₅ |

**Round 3 结束后（Reduce-Scatter 结束）：**

| 段 \ Rank | Rank 0 | Rank 1 | Rank 2 |
|-----------|--------|--------|--------|
| 段 0      | **S₀** | a₀+b₀  | S₀     |
| 段 1      | **S₁** | a₁+b₁  | S₁     |
| 段 2      | S₂     | **S₂** | S₂     |
| 段 3      | S₃     | **S₃** | S₃     |
| 段 4      | a₄+c₄  | S₄     | **S₄** |
| 段 5      | a₅+c₅  | S₅     | **S₅** |

即：**Rank 0 拥有段 0,1 的完整和 S₀,S₁；Rank 1 拥有段 2,3 的 S₂,S₃；Rank 2 拥有段 4,5 的 S₄,S₅**。段与 Rank 的对应关系为「段 0,1→R0；段 2,3→R1；段 4,5→R2」。

# 阶段二：AllGather（沿环收齐各块）

Reduce-Scatter 结束后，每个 Rank 只「拥有」自己归宿的那一块完整（R0 有块0，R1 有块1，R2 有块2）。**AllGather** 沿环把这三块再传一遍，使每人最终都拥有 [S₀,S₁,S₂,S₃,S₄,S₅]。

## AllGather 约定

- **环与方向**：仍为 R0 → R1 → R2 → R0，每轮每人向**右邻居**发 1 块、从**左邻居**收 1 块。
- **发送规则**：每轮每个 Rank 发送的是**对方还没有的那一块**（自己刚收到或原本拥有的）；收到后直接**写入**对应段（覆盖或拼接），不做规约。
- **轮数**：N 个 Rank 时 **N−1 = 2 轮**，即可让人人收齐全部 3 块。

## AllGather 初始状态（= Reduce-Scatter 结束）

为书写简洁，这里只标出「已确定拥有的块」；未写出的段可视为待 AllGather 填满。

| 段 \ Rank | Rank 0 | Rank 1 | Rank 2 |
|-----------|--------|--------|--------|
| 段 0,1（块0） | **S₀,S₁** | —       | —       |
| 段 2,3（块1） | —       | **S₂,S₃** | —       |
| 段 4,5（块2） | —       | —       | **S₄,S₅** |

---

## AllGather Round 0

每人把**自己拥有的块**发给右邻居；对方收到后写入对应段。

**发送/接收：**

| Rank | 发送               | 接收来自 | 操作 |
|------|--------------------|----------|------|
| 0    | 块0(S₀,S₁) → R1    | R2 块2   | 段4:=S₄，段5:=S₅（写入） |
| 1    | 块1(S₂,S₃) → R2    | R0 块0   | 段0:=S₀，段1:=S₁（写入） |
| 2    | 块2(S₄,S₅) → R0    | R1 块1   | 段2:=S₂，段3:=S₃（写入） |

**Round 0 结束后：**

| 段 \ Rank | Rank 0     | Rank 1     | Rank 2     |
|-----------|------------|------------|------------|
| 段 0,1    | S₀,S₁      | S₀,S₁      | —          |
| 段 2,3    | —          | S₂,S₃      | S₂,S₃      |
| 段 4,5    | S₄,S₅      | —          | S₄,S₅      |

即：R0 已有块0+块2；R1 已有块0+块1；R2 已有块1+块2。

---

## AllGather Round 1

每人把**上一轮收到、且右邻居还没有的那一块**发给右邻居。

**发送/接收：**

| Rank | 发送               | 接收来自 | 操作 |
|------|--------------------|----------|------|
| 0    | 块2(S₄,S₅) → R1    | R2 块1   | 段2:=S₂，段3:=S₃（写入） |
| 1    | 块0(S₀,S₁) → R2    | R0 块2   | 段4:=S₄，段5:=S₅（写入） |
| 2    | 块1(S₂,S₃) → R0    | R1 块0   | 段0:=S₀，段1:=S₁（写入） |

**Round 1 结束后（AllGather 结束）：**

| 段 \ Rank | Rank 0 | Rank 1 | Rank 2 |
|-----------|--------|--------|--------|
| 段 0      | S₀     | S₀     | S₀     |
| 段 1      | S₁     | S₁     | S₁     |
| 段 2      | S₂     | S₂     | S₂     |
| 段 3      | S₃     | S₃     | S₃     |
| 段 4      | S₄     | S₄     | S₄     |
| 段 5      | S₅     | S₅     | S₅     |

**每个 Rank 都拥有完整结果 [S₀,S₁,S₂,S₃,S₄,S₅]**，Ring AllReduce 完成。

---

## 环与收发关系简图

```
发送方向：R0 → R1 → R2 → R0

  Rank0 ──(块0/1/2)──► Rank1 ──(块0/1/2)──► Rank2 ──(块0/1/2)──► Rank0
     ▲                                                                  │
     └──────────────────── 接收来自左邻居 ──────────────────────────────┘
```

- **Reduce-Scatter**：每轮每人发 1 块、收 1 块；块号按 `(i + r) mod 3` 轮换；收到后做 += 或替换。**AllGather**：同环同向，每轮每人把「对方还没有的一块」发给右邻居，收到后写入对应段，不做规约。

---

## 小结

| 项目           | 说明 |
|----------------|------|
| 段数 / Rank 数 | **6 段**（数据划分）、**3 Rank**（进程），段 ≠ Rank |
| 块             | 2 段为一块，共 3 块，与 3 个 Rank 一一对应 |
| **Reduce-Scatter** | 4 轮（3 轮规约 + 1 轮送归宿）；结束后每 Rank 拥有自己归宿块的 Sⱼ |
| **AllGather**  | 2 轮（N−1）；每人把已有块沿环转发，最终人人收齐 [S₀..S₅] |
| **Ring AllReduce** | 上述两阶段合计：先分段规约到各 Rank，再沿环收齐，得到完整 AllReduce 结果 |

### 轮数（N = rank 数）

| 阶段 | 轮数 | 说明 |
|------|------|------|
| **Reduce-Scatter** | **N** 轮 | 规约完成只需 N−1 轮（每块沿环走 N−1 步即收齐）；本步骤表多写了一轮「送块到归宿」，故共 **N** 轮。常见也有只计规约的写法，即 N−1 轮。 |
| **AllGather** | **N−1** 轮 | 每人把已有块沿环转发 N−1 次即收齐全部块，不是 N 轮。 |
| **Ring AllReduce 总轮数** | 约 **2N−1** 或 **2(N−1)** | Reduce-Scatter（N 或 N−1）+ AllGather（N−1），与 rank 数同量级，但不是「总共 N 轮」。 |

**记忆**：Reduce-Scatter 约 N 轮（或 N−1 轮），AllGather 为 N−1 轮；两阶段相加约 2N 量级。

---

这样**段**与**Rank**概念分离：段是数据下标（0～5），Rank 是进程下标（0～2），对应关系由「块归宿」决定。
